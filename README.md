# Frevolt Leegality Plugin

A Flutter plugin for integrating Leegality e-signature functionality into FlutterFlow applications.

## Features

- Start Leegality signing process from Flutter/FlutterFlow
- Customizable zoom and timer settings
- Handle signing results and errors
- Broadcast event support

## Installation

Add to your `pubspec.yaml`:

```yaml
dependencies:
  frevolt_leegality_plugin:
    git:
      url: https://github.com/vijayfrevolt/frevolt_leegality_plugin.git
